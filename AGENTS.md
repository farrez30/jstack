# Konvensi repo

Aturan lintas repo ada di [standar/AGENTS.base.md](standar/AGENTS.base.md) —
baca itu dulu. Berkas ini hanya memuat yang khusus repo ini, dan masih kosong:
isi begitu ada keputusan yang hanya benar di sini, bukan di repo lain.

Yang biasanya masuk: cara setup & run yang berbeda dari umumnya, nama gate
sebelum commit kalau bukan `npm run check`, jebakan lingkungan yang cuma
terjadi di sini, dan berkas yang tidak boleh disentuh tanpa alasan kuat.
